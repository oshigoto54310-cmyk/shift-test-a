# 操作マニュアル（店舗担当者・ベンダー担当者向け）

スマートフォンからの操作を前提に説明します。PC でも同じ手順で操作できます。

---

## 共通操作

### ログイン

1. ブラウザでシステムのURLを開きます。
2. **メールアドレス** と **パスワード** を入力し、「ログイン」を押します。
3. 画面上部に自分の名前と権限（店舗担当者／ベンダー担当者）が表示されれば成功です。

> パスワードを忘れた場合は「パスワード再設定」を押し、メールアドレスを入力してください。
> 再設定用のトークンがメールで届きます。

**ログインできないとき**

| 表示 | 対処 |
|---|---|
| メールアドレスまたはパスワードが正しくありません | 入力内容を確認してください |
| ログイン失敗が続いたためロックされています | 表示された時間だけ待つか、管理者にロック解除を依頼してください |
| このアカウントは停止されています | 管理者に連絡してください |

### ホーム画面に追加する（スマートフォン）

毎回URLを入力しなくて済むよう、ホーム画面への追加をおすすめします。

- iPhone（Safari）: 共有ボタン → 「ホーム画面に追加」
- Android（Chrome）: メニュー → 「ホーム画面に追加」

### 画面の見かた

- 画面上部に自分の情報、その下にメニューが並びます。
- 主要なボタン（保存・確定・戻る）は **常に画面下部** に固定されています。
- 状態は色だけでなく **アイコンと文字** で表示されます。

| 表示 | 意味 |
|---|---|
| ✎ 下書き | 一時保存中。まだ発注していません |
| ✔ 発注確定 | 発注が確定しています |
| ⏳ ベンダー未確認 | ベンダーがまだ確認していません |
| 👁 ベンダー確認済み | ベンダーが受注を確認しました |
| ◐ 一部納品 | 一部しか納品できません |
| ✖ 欠品 | 納品できません |
| ⇄ 代替提案 | ベンダーから代わりの商品の提案があります |
| 📦 納品確定 | 全数納品が確定しました |
| 📝 変更申請中 | 締め後の変更を申請しています |
| ⊗ 取消 | 発注が取り消されました |

### 通知

メニューの「通知」に未読件数が表示されます。
発注確定・欠品・一部納品・変更承認などがあると通知が届きます。

---

# 店舗担当者の操作

## 1. 発注する

### 手順

1. メニューから **「発注入力」** を選びます。
2. **納品日** を選びます（過去の日付は選べません）。
3. 商品を探します。4つの方法があります。

   | タブ | 使いどころ |
   |---|---|
   | 商品検索 | 商品名・JANコード・自社商品コードで探す |
   | お気に入り | よく発注する商品をすぐ出す |
   | 前回発注商品 | 最近発注した商品から選ぶ |
   | 前回発注をコピー | 前回と同じ内容をまとめて入れる |

4. 商品の **「カゴに追加」** を押します。
5. 画面下の「発注カゴ」で数量を入力します。

   - **ケース** … ケース単位の数量
   - **バラ** … ばら単位の数量
   - − / ＋ ボタン、または数字を直接入力できます
   - 合計数量（バラ換算）が自動計算されます

6. 下部の **「発注確定」** を押します。
7. 確認画面が出ます。納品日・明細数・合計数量を確認して **「発注確定」** を押します。

> あとで直したい場合は **「一時保存」** を押してください。下書きとして保存され、
> 発注一覧から続きを編集できます。ベンダーには通知されません。

### 確認画面に警告が出たとき

| 警告 | 意味 | 対処 |
|---|---|---|
| 同じ納品日に既に発注があります | 重複発注の可能性 | 既存の発注を確認してください |
| 数量が通常より大きい値です | 桁を間違えている可能性 | 数量を見直してください |
| 数量が0です | 入力漏れの可能性 | 数量を入力してください |
| 原価が未登録です | マスタ未整備 | 本部に連絡してください |
| バラ数がケース入数以上です | ケース数に繰り上げたほうが正確 | 入力を見直してください |
| 締め時間を過ぎています | 締め後の登録 | 本部に相談してください |

これらは警告なので、確認したうえでそのまま登録できます。
一方、**「登録できません」と出た場合は登録が中止されます**（過去日の納品日、
バラ発注できない商品へのバラ入力など）。表示された内容を直してください。

### 商品はベンダーごとに自動で分かれます

複数ベンダーの商品をまとめてカゴに入れても、
登録時に **ベンダーごとの発注に自動的に分割** されます。ベンダーを意識する必要はありません。

## 2. 発注を修正する（締め時間前）

1. **「発注一覧」** から対象の発注を開きます。
2. 下部の **「数量を修正」** を押します。
   - このボタンが出ないときは、締め時間を過ぎているか、すでにベンダーが処理を始めています。
3. ± ボタンまたは数字入力で数量を直します。
4. 必要に応じて **変更理由** を入力します。
5. **「保存」** を押し、確認画面で「変更前 → 変更後」を確認して保存します。

> 修正内容は必ず履歴に残ります。誰がいつ何を変えたかが記録されます。

## 3. 締め時間を過ぎてから変更したい（変更申請）

締め時間を過ぎると数量を直接変更できません。
発注明細画面に「締め時間を過ぎています」と表示され、修正ボタンが消えます。

### 手順

1. 発注明細を開き、変更したい商品の **「締め後の変更申請」** を押します。
2. 変更後のケース数・バラ数を入力します。
3. **変更理由を必ず入力** します（例: 天候不良により需要が減少したため）。
4. 「申請する」を押します。

### 申請後の流れ

```
申請      →  本部が承認/却下  →  ベンダーが確認
（数量は        （承認されると       （正式数量として
  まだ変わらない）  数量が変わる）      反映される）
```

- 申請中の商品は「📝 変更申請中」と表示されます。
- 承認・却下の結果は通知で届きます。
- 却下された場合は理由が表示され、数量は元のままです。
- 進捗はメニューの **「変更申請」** から確認できます。

## 4. ベンダーの回答を確認する

発注明細画面で、ベンダーからの回答を色付きの帯で確認できます。

| 表示 | 意味 | 見るべき項目 |
|---|---|---|
| ◐ 一部納品可能 | 一部しか納品できない | 納品可能数量・不足数量・理由 |
| ✖ 欠品 | 納品できない | 欠品理由・次回納品可能日 |
| ⇄ 代替商品提案 | 代わりの商品の提案 | 代替商品名・数量・承認状況 |
| 📦 全数納品可能 | 発注どおり納品される | — |

代替商品の提案は **本部の承認後に確定** します。「（本部承認待ち）」と表示されている間は未確定です。

## 5. 発注を取り消す

発注明細画面から取り消せます。取消理由の入力が必要です。
締め時間を過ぎている場合、店舗からは取り消せません。本部に相談してください。

## 6. 履歴を見る

メニューの **「履歴」** から確認できます。

- **数量変更履歴** … いつ誰がどう変えたか（締め前／締め後の区別つき）
- **ステータス履歴** … 発注の状態がどう変わったか
- **ベンダー回答** … これまでの回答内容

履歴は削除できません。「言った・言わない」の確認に使ってください。

# ベンダー担当者の操作

## 1. 受注を確認する

1. ログインすると **「受注一覧」** が開きます。自社あての発注だけが表示されます。
2. 納品日で絞り込めます。
3. 発注カードの **「受注確認」** を押すと、発注を受け付けたことが店舗・本部に通知されます。

> 店舗が一時保存しただけの発注（下書き）は表示されません。
> 確定された発注のみが届きます。

## 2. 商品ごとに回答する

各商品に4つのボタンがあります。

### 全数納品

発注どおり納品できる場合。ボタンを押して確認するだけです。

### 一部納品

一部しか納品できない場合。

| 入力項目 | 必須 |
|---|:-:|
| 納品可能数量（発注数量より少ない数） | ○ |
| 理由 | ○ |

不足数量は自動計算されます。

### 欠品

まったく納品できない場合。

| 入力項目 | 必須 |
|---|:-:|
| 欠品理由 | ○ |
| 次回納品可能日 | — |

### 代替提案

代わりの商品を提案する場合。

| 入力項目 | 必須 |
|---|:-:|
| 代替商品名 | ○ |
| 納品可能数量 | ○ |
| JANコード / 規格 / 原価 / 納品可能日 / コメント | — |

> **代替商品は本部の承認後に確定します。** 提案しただけでは確定しません。

### 回答をやり直したいとき

同じ商品にもう一度回答すれば、新しい回答が最新になります。
**前の回答も履歴として残ります**（消えません）。「回答履歴」で確認できます。

## 3. 数量を集計する

メニューの **「集計」** で、出荷準備に使う数字を確認できます。

| タブ | 内容 |
|---|---|
| 商品別合計 | 商品ごとの合計数量と、**店舗別の内訳** |
| 納品日別 | 納品日ごとの件数・数量・未回答件数 |
| 店舗別 | 店舗ごとの合計数量 |

すべて自社分のみが表示されます。他社の商品・数量・原価は表示されません。

## 4. 締め後の変更を確認する

店舗からの変更申請が本部に承認されると通知が届きます。

1. メニューの **「変更申請」** を開きます。
2. 「承認済み」の申請に **「変更内容を確認」** ボタンが表示されます。
3. 押すと、変更後の数量が正式数量として確定します。

## 5. 回答履歴を見る

メニューの **「回答履歴」** から、これまでの回答を確認できます。
訂正した回答は「訂正前」ラベル付きで残ります。

---

## 困ったときは

| 症状 | 対処 |
|---|---|
| 「通信に失敗しました」と出る | 電波状況を確認してもう一度お試しください。保存されていない入力は残っています |
| 「この操作は既に受け付けています」と出る | ボタンの二度押しです。一覧を確認すると登録されています |
| 「締め時間を過ぎているため直接変更できません」と出る | 変更申請から本部に依頼してください |
| 「この操作を行う権限がありません」と出る | 自分の担当範囲外のデータです。本部・管理者に確認してください |
| ログイン画面に戻ってしまう | セッションの有効期限（既定8時間）が切れています。再度ログインしてください |
| ボタンが「処理中...」のまま | 通信中です。しばらく待っても変わらない場合は画面を再読み込みしてください |
