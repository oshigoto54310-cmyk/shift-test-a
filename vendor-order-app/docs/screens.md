| 画面 | 管理者 | 本部 | 店舗 | ベンダー |

| ログイン | ○ | ○ | ○ | ○ |
| 本部ダッシュボード | ○ | ○ | × | × |
| 発注一覧 | ○ | ○ | ○ | × |
| 発注明細 | ○ | ○ | ○ | ○ |
| 発注入力 | ○ | ○ | ○ | × |
| 数量修正（締め前） | ○ | ○ | ○ | × |
| 変更申請 | ○ | ○ | ○ | ○（確認のみ） |
| ベンダー受注一覧 | × | × | × | ○ |
| 集計 | ○ | ○ | × | ○ |

| 履歴 | ○ | ○ | ○ | × |

---

## 1. ログイン画面

- メールアドレス
- パスワード
- ログインボタン
- パスワード再設定

エラーは「メールアドレスまたはパスワードが正しくありません」と統一し、
アカウントの存在有無を漏らしません。ログイン失敗が5回続くと15分ロックされます。

---

## 2. 本部ダッシュボード（管理者・本部）

画面上部に **ベンダー切替 / 店舗切替 / 納品日切替** を常時表示します。

タイル（タップで該当一覧へ移動）:

| タイル | 内容 |
|---|---|
| ⏰ 本日締め | 本日中に最終締めを迎える発注件数 |
| ✎ 未確定 | 下書き・発注予定のままの発注件数 |
| ⏳ ベンダー未確認 | ベンダーがまだ確認していない明細数 |
| ⚠ 回答期限超過 | 回答期限を過ぎても未確認の明細数 |
| ✖ 欠品 | 欠品明細数 |
| ◐ 一部納品 | 一部納品明細数 |
| ⇄ 代替提案 | 代替提案中の明細数 |
| 📝 変更申請 | 承認待ちの変更申請数 |

下部に直近の発注カードを表示します。

---

## 3. 発注入力画面

商品を検索してカゴに入れ、数量を入力して確定します。

**商品の探し方（4つのタブ）**

| タブ | 内容 |
|---|---|
| 商品検索 | 商品名 / JANコード / 自社商品コードの部分一致。分類・ベンダーで絞り込み可 |
| お気に入り | 店舗ごとに登録したお気に入り商品 |
| 前回発注商品 | 直近で発注した商品を新しい順に表示 |
| 前回発注をコピー | 前回の発注内容をそのままカゴに入れる |

**発注カゴ**

商品ごとにカードで表示し、それぞれに以下を用意します。

- ケース数（− / 数値入力 / ＋）
- バラ数（− / 数値入力 / ＋）
- 合計数量（バラ換算）の自動計算

数値入力欄は `inputmode="numeric"` を指定しており、スマートフォンでは数字キーボードが開きます。
発注単位が「ケース」の商品はバラ入力欄が、「バラ」の商品はケース入力欄が自動的に無効化されます。

**下部固定バー**: 一時保存 / 発注確定

確定前に確認ダイアログが開き、納品日・明細数・合計数量と、
入力チェックの警告（重複発注・異常数量・原価未登録など）が一覧表示されます。

---

## 4. 発注一覧画面

ステータスのチップで絞り込みます（すべて / 下書き / 発注確定 / ベンダー未確認 / 欠品 / 一部納品 / 変更申請中）。

1カードに表示する項目:

- 発注番号
- 店舗名 → ベンダー名
- ステータス（アイコン＋文字＋色）
- 納品日 / 明細数 / 合計数量 / 締め時間

---

## 5. 発注明細画面

- 発注ステータス、最終締め、回答期限、合計数量、確定日時
- 締め後は「締め時間を過ぎています」の警告帯を表示
- 明細カードごとに: 商品名 / 規格 / JAN / ケース・バラ・発注数量 / 確定数量 / ステータス
- ベンダー回答があれば、回答区分・納品可能数量・不足数量・理由・次回納品可能日・代替提案を表示
- この発注の変更履歴をタイムラインで表示（締め後変更は赤い印で区別）

**下部固定バー**: 戻る / 数量を修正（締め前のみ） / 発注確定 / 受注確認（ベンダー）

---

## 6. 数量修正画面（締め前のみ）

明細ごとに ± ボタンと数値入力で数量を修正します。
変更理由を任意入力でき、保存前に「変更前 → 変更後」の一覧を確認ダイアログで表示します。
未保存のまま画面を離れようとすると警告が出ます。

---

## 7. ベンダー受注一覧画面

自社あての発注のみ表示します。**ベンダー切替UIは表示しません。**

発注カードの中に明細カードが入る構造で、明細ごとに4つの回答ボタンを配置します。

| ボタン | 入力項目 |
|---|---|
| 全数納品 | （確認のみ） |
| 一部納品 | 納品可能数量（必須）、理由（必須） |
| 欠品 | 欠品理由（必須）、次回納品可能日 |
| 代替提案 | 代替商品名（必須）、JAN、規格、原価、納品可能数量（必須）、納品可能日、コメント |

発注カード単位で「受注確認」ボタンを表示します。

---

## 8. 集計画面（ベンダー・本部）

| タブ | 内容 |
|---|---|
| 商品別合計 | 商品ごとの合計数量・合計ケース・合計バラ・発注店舗数と、**店舗別内訳** |
| 納品日別 | 納品日ごとの発注件数・明細数・合計数量・未回答・欠品・一部納品 |
| 店舗別 | 店舗ごとの発注件数・合計数量 |

---

## 9. 変更申請画面

申請カードに「変更前 → 申請数量」「変更理由」「申請者」「申請日時」を表示します。

- 本部・管理者: 承認 / 却下（却下は理由必須）
- ベンダー: 承認済みの変更を確認
- 店舗: 自分の申請の状況を確認

---

## 10. 履歴画面

| タブ | 内容 | 権限 |
|---|---|---|
| 数量変更履歴 | 変更前後の数量・ケース・バラ、理由、変更者、締め前/締め後 | 全員（スコープ適用） |
| ステータス履歴 | ステータス遷移 | 全員（スコープ適用） |
| ベンダー回答 | 回答区分・数量・理由 | 全員（スコープ適用） |
| 操作ログ | 日時・ユーザー・権限・操作・対象・詳細 | 管理者・本部 |
| 通知履歴 | 送信日時・チャネル・宛先・種別・結果 | 管理者・本部 |
| ログイン履歴 | 日時・メール・成否・理由・IP | 管理者 |

**履歴を削除する操作は用意していません。**

---

## 11. 回答履歴画面（ベンダー）

自社の回答履歴。訂正した場合、古い回答も「訂正前」ラベル付きで残ります。

---

## 12. 出力画面（管理者・本部）

各項目に Excel / CSV / 印刷（PDF） のボタンを配置します。

ベンダー別発注一覧 / 店舗別発注一覧 / 商品別集約 / 納品日別集約 / 欠品一覧 /
一部納品一覧 / 未回答一覧 / 変更申請一覧 / 発注変更履歴 / 操作ログ

出力範囲は画面上部の切替（ベンダー・店舗・納品日）に連動します。

---

## 13. 通知画面

自分あての通知を新しい順に表示。未読・既読をバッジで区別し、
「すべて既読にする」と、通知から該当発注を開く導線があります。
ナビゲーションの「通知」には未読件数バッジが付きます。

---

## 14. マスタ管理画面（管理者）

| タブ | 操作 |
|---|---|
| 店舗 | 一覧・追加 |
| ベンダー | 一覧・追加 |
| 商品 | 一覧（表形式）・追加。担当ベンダーの指定が必須 |
| ユーザー | 一覧・追加・ロック解除・アカウント停止。最終ログイン日時と失敗回数を表示 |
| 締め時間 | 一覧・追加。優先順位（商品別 → ベンダー別 → システム標準）を画面上に明示 |
| 理由 | 変更理由・欠品理由の一覧・追加 |

## UI方針の実装

| 方針 | 実装 |
|---|---|
| 現場担当者が迷わない | メニューは権限ごとに必要なものだけ表示 |
| 文字を小さくしすぎない | 本文16px基準。ラベル最小12.5px |
| ボタンを押しやすくする | 主要ボタンは最小高さ44px、± ボタンは46×46px |
| ステータスを文字とアイコンで表示 | 全ステータスにアイコン＋日本語ラベルを併記 |
| 色だけで状態を判別させない | バッジは「アイコン＋文字＋色」の3要素 |
| 重要情報を上部に表示 | ステータス・締め時間をカード上部に配置 |
| 入力項目を増やしすぎない | 発注入力はケース数・バラ数・納品日のみ |
| スマホでは縦スクロール中心 | 一覧はカード形式。主要画面で横スクロールなし（実機幅390pxで検証済み） |
| PCでは一覧性を優先 | 768px以上でタイル4列・グリッド4列に変化。商品マスタや操作ログは表形式 |
| 保存・確定・戻るの位置を統一 | 常に画面下部の固定バー。左が「戻る」、右が主要操作 |
| エラー内容を具体的に表示 | 「〇〇は必須です」「〇〇はバラ発注できません」など対象名を含めて表示 |

## 誤操作防止の実装

| 対策 | 実装箇所 |
|---|---|
| 確定前確認画面 | 発注確定・数量修正・受注確認・回答・承認・却下すべてに確認ダイアログ |
| 削除前確認 | カゴからの削除、アカウント停止 |
| 二重送信防止 | ボタンを「処理中...」に切り替えて無効化＋サーバー側で `client_token` を一度だけ受付 |
| 未保存警告 | 画面移動時とブラウザを閉じるときに警告 |
| 通信失敗表示 | 「通信に失敗しました。電波状況を確認して...」のトースト |
| 保存完了表示 | 「保存しました」「発注を確定しました」のトースト |
| 締め後直接編集禁止 | 締め後は修正ボタン自体を出さず、サーバー側でも409で拒否 |
